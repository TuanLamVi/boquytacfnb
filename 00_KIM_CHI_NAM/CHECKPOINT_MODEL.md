# CHECKPOINT MODEL

## Chuỗi

```
PASS
→ PO_VERIFIED
→ REGRESSION CHECK
→ PROTECTED
→ LOCKED
```

## LOCKED bảo vệ

- hành vi;
- quy tắc;
- invariant;
- acceptance criteria;
- evidence;
- phạm vi đã chấp nhận.

Không đồng nghĩa khóa cứng file.

## Trước thay đổi

```
CURRENT A-STAGE
TASK
RELATED A-STAGES
LOCKED SCOPE IMPACT
```

- NONE → tiếp tục.
- DETECTED → REGRESSION_REQUIRED.
- UNKNOWN → REGRESSION_RISK + STOP.

Chỉ PO được UNLOCK.
