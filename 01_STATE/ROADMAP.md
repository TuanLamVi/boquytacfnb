# ROADMAP — CANONICAL ORDER

Roadmap canonical:

```
A0 → A1 → A2 → A3 → A4 → A5 → A6 → A7 → A8 → A9 → A10 → A11
```

## Quy tắc

- Child PASS không tự nâng parent.
- ID mới dùng dạng hyphen, ví dụ A0-01, A2-02.
- ID cũ/decimal giữ như historical reference.
- Không tự suy diễn crosswalk giữa các hệ thống ID cũ và mới.

Chi tiết roadmap lịch sử nằm trong tài liệu nguồn migration.
